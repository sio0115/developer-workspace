# developer-workspace
코디세이 개발자 작업실 구축 미션 - 터미널, Docker, Git 실습 기록


## 개발 환경

- Windows
- WSL2
- Ubuntu 24.04
- Docker Desktop
- Git
- Visual Studio Code

## 실습 내용

### 1. Linux 터미널 및 파일 관리
- 디렉터리 이동과 파일 목록 확인
- 파일 생성, 복사, 이동 및 이름 변경
- Linux 파일 권한과 사용자 그룹 확인

### 2. Git 및 GitHub
- Git 저장소 생성 및 복제
- 파일 변경 사항 추적
- add, commit, push 실습
- GitHub 원격 저장소 연동

### 3. Docker
- Docker 이미지 및 컨테이너 실행
- Dockerfile 작성 및 사용자 정의 이미지 생성
- Nginx 컨테이너 포트 매핑 실습
- Bind Mount를 이용한 호스트 파일 연결
- Docker Volume을 이용한 데이터 영속성 확인
